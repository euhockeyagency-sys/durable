# Вебвизор на формах: проверка 19.11.2026 (пакет C)

- Код сайта: `ym(110889446,'init',{webvisor:true,…})` вызывается только после согласия (`public/site.js`). До согласия грузится лишь `tag.js`.
- Прод, профиль без согласия: запросов `mc.yandex.*/watch` нет, GA4 отправляет cookieless-пинг `gcs=G1-0` (Consent Mode, хранение запрещено).
- Прод, после согласия, синтетический маркер в полях формы (без отправки): за 20 с не перехвачено ни одного исходящего payload через sendBeacon/fetch/XHR — Метрика отправляет данные Вебвизора своими средствами и пакетами. **Вывод: записывались ли поля раньше, браузерной проверкой не установлено.** Это предел проверки без доступа к счётчику.
- Не проверено (нет доступа): настройка счётчика «Записывать все поля» / «Запись содержимого полей» и сами записи Вебвизора за прошлые периоды.

## Что сделать владельцу в Метрике (5 минут)

1. Счётчик 110889446 → Настройка → Вебвизор: проверить, включено ли «Записывать все поля». Безопаснее выключить: тогда записываются только поля с `ym-record-keys` (таких на сайте нет).
2. Вебвизор → открыть 2–3 визита на `/contact` после деплоя: в полях должны быть звёздочки, форма — размытой.
3. Если в старых записях видны данные игроков, удалить эти визиты или сократить срок хранения записей Вебвизора.
