Fonts for the server-side PDF player card (src/intake/player-card-pdf.js).

Manrope and Oswald are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org). These static TTF instances (Manrope 400/700,
Oswald 600; Latin, Latin Extended and Cyrillic) were built from the site's own
woff2 files in public/assets/fonts with fontTools (variable font instanced at
the given weight, subsets merged). Not served publicly.
